TrueNAS Server

Main NAS system for storage, media serving, and data redundancy.

Exists in VLAN 30

Hardware

  • CPU: Intel Core i5-10400
  • RAM: 64 GB DDR4
  • NICs: 1GbE onboard + 5Gbps Aquantia PCIe
  • Storage Pools:
    • Pool1: 4×10TB (striped mirror)
    • Pool2: 2×12TB (striped mirror)

Services

  • TrueNAS Core (ZFS)
  • NFS exports to Debian Server & Jellyfin
  • Snapshot-based backup and scrub scheduling
  • Proxmox VM NFS storage
