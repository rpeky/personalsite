MikroTik Router (RB750Gr3)

There is currently a RB5009UG+S+IN that is prepared in my 10u rack ready for the RB750Gr3 to migrate to.

Purpose

Primary routing, firewall, and VLAN management device for the entire homelab.

Hardware RB750Gr3

  • Model: MikroTik hEX RB750Gr3
  • 5× Gigabit Ethernet ports
  • Dual-core 880 MHz CPU, 256MB RAM

Hardware RB5009UG+S+IN

  • Model: MikroTik RB750Gr3
  • 7× Gigabit Ethernet ports
  • 1× 2.5 Gigabit Ethernet port
  • 1× SFP+ port populated with S+RJ10 module
  • Quad-core 1.4 GHz CPU, 1GB RAM

Roles

  • Static routing and NAT
  • WireGuard VPN endpoint
  • VLAN-aware configuration with tagged interfaces
